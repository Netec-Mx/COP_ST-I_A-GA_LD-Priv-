# Carpeta de imágenes

Carpeta **única** de imágenes del repositorio. No se crean carpetas `images` dentro de los capítulos.

Aquí se guardan únicamente las evidencias que solicitan los laboratorios. Cada práctica indica, en su sección **Validación y Pruebas**, el nombre exacto de cada captura.

## Convención de nombres

```text
evidencia-capXX-pY-descripcion.png
```

| Parte | Significado | Ejemplo |
|---|---|---|
| `capXX` | Número de capítulo con dos dígitos | `cap04` |
| `pY` | Número de práctica | `p5` |
| `descripcion` | Contenido de la captura, en minúsculas y con guiones | `lista` |

Ejemplo completo: `evidencia-cap04-p5-lista.png`.

## Reglas

- No incluyas datos personales, credenciales, tokens ni información bancaria real en las capturas.
- Recorta la captura para mostrar solo el área solicitada.
- Usa formato PNG.
